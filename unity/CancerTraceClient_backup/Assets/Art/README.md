# Art 美术资源

- `Background/`：主菜单、病例室、星图等背景。
- `UI/`：面板、按钮、标签、边框和贴纸。
- `Character/`：小侦探、猫咪助手及其他角色。
- `Cells/`：癌细胞插画、细胞卡片和展示素材。
- `Icons/`：癌症类别、调查操作、状态与通用图标。
- `Biology/`：DNA、基因、染色体及实验室相关元素。
- `Effects/`：扫描、发现、正确/错误反馈等视觉效果。

建议统一使用小写英文前缀和下划线命名，例如：

- `bg_*.png`
- `ui_btn_*.png`
- `icon_*.png`
- `char_*.png`
- `cell_*.png`

导入正式素材时应同时记录来源、作者和授权信息。
