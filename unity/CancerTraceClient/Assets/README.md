# Assets 目录说明

- `Art/`：背景、界面、角色、细胞、图标、生物学元素和特效素材。
- `Audio/`：背景音乐与交互音效。
- `Fonts/`：中文字体及其授权说明。
- `Materials/`：Unity 材质资源。
- `Prefabs/`：界面、角色和细胞展示预制体。
- `Resources/`：仅存放确实需要通过 Unity Resources API 动态读取的内容。
- `Scenes/`：Unity 场景。
- `Scripts/`：按 Core、Data、UI、Gameplay、Debug 分层的脚本目录。
- `StreamingAssets/`：运行时按原文件读取的游戏数据。
- `UIStyleGuide/`：界面风格、颜色、字号、间距与组件规范。

整体美术风格以中文界面为主，强调可爱、手账、侦探、温暖和轻松的体验。避免冷冰冰的科技风、过度霓虹效果和刻意的 AI 视觉符号。
