# CancerTrace 美术风格指南

版本：v1.0

项目名称：

CancerTrace：癌症溯源计划


---

# 1. 文档目的

本文档用于统一 CancerTrace 项目的视觉设计方向。

所有：

- UI界面
- 游戏背景
- 角色设计
- 图标
- 生物元素
- 特效资源

均需要遵循本文档规范。

本文档作为项目美术设计的最高参考标准。


---

# 2. 游戏视觉定位

## 项目定位

CancerTrace 是一款结合：

- 生物信息学
- 癌症分类
- AI辅助分析
- 侦探推理

的教育探索类游戏。


玩家身份：

一名“小小细胞侦探”。


玩家通过：

- 观察细胞样本
- 收集基因线索
- 分析证据
- 使用调查工具
- 完成癌症来源推理

逐步探索生命科学知识。


---

# 3. 整体美术风格


## 风格名称

可爱手账侦探风

Cute Scrapbook Detective Style


---

## 核心关键词

所有素材设计应符合：

- cute
- hand drawn
- scrapbook
- pastel color
- warm laboratory
- biology detective
- sticker style
- rounded shape
- educational game


---

## 视觉特点


### 3.1 手账感

界面应具有：

- 笔记本纸张
- 便签
- 胶带
- 图钉
- 手绘线条
- 贴纸装饰


整体感觉：

像一本记录生命秘密的侦探研究笔记。


避免：

- 工业化UI
- 软件后台风格
- 数据监控平台风格


---

### 3.2 温暖感

整体氛围：

- 友好
- 轻松
- 好奇
- 探索


玩家体验应该类似：

“探索生命秘密的小侦探”

而不是：

“操作医疗诊断系统”。


---

### 3.3 可爱化科学元素

科学元素需要进行游戏化处理。


例如：

## 细胞

应该：

- 彩色
- 圆润
- 可爱
- 具有辨识度


## DNA

应该：

- 简洁
- 卡通化
- 作为探索和线索符号


## 显微镜

应该：

- 插画风
- 具有探索感


禁止：

- 真实医学图片风格
- 恐怖病理展示

# 5. 色彩规范


## 主色调

整体采用：

柔和浅色系。


推荐颜色：


暖白：

```
#FFF7EE
```


浅粉：

```
#F7C6C7
```


薄荷绿：

```
#B8E3D0
```


浅蓝：

```
#B9DDF5
```


浅紫：

```
#D8C8F0
```


浅黄色：

```
#FFE28A
```


---

## 使用原则

颜色主要用于：

- 区分模块
- 强调信息
- 增强亲和感


避免：

- 高饱和霓虹色
- 大面积黑色
- 冷色科技蓝


---

# 6. UI设计规范


## UI整体方向

UI应该像：

“科学侦探的研究笔记”。


而不是：

“实验室控制终端”。


---

## UI元素特点

推荐使用：

- 圆角卡片
- 手绘边框
- 纸张纹理
- 贴纸效果
- 胶带装饰
- 图钉元素
- 柔和阴影


例如：

线索卡：

应该像玩家贴在调查本上的证据。


---

## 按钮设计


按钮应该：

- 圆润
- 有立体感
- 像贴纸


状态设计：

正常：

普通贴纸效果


悬停：

轻微放大


点击：

轻微缩放反馈


禁止：

- 默认Unity按钮样式
- 工业软件按钮


---

# 7. 页面视觉要求


## MainMenu.unity

定位：

玩家进入实验室的入口。


应该包含：

- 温暖实验室环境
- 实验桌
- 显微镜
- 书籍
- 植物
- 小助手角色


整体感觉：

欢迎玩家开始探索。


---

## CaseAnalysis.unity

核心游戏页面。


定位：

侦探调查桌。


需要突出：

- 病例信息
- 初始线索
- Gene Scan
- Evidence Board
- 诊断选择


视觉感觉：

像整理案件证据。


---

## CancerGalaxy.unity

定位：

癌症样本探索地图。


注意：

不是宇宙科幻页面。


应该表现：

- 生物数据探索
- 样本关系
- 细胞连接


使用：

- 柔和星点
- 手绘节点
- 轻量连线


---

## ResultSummary.unity

定位：

调查报告。


包含：

- 病例结果
- 玩家判断
- AI分析
- 得分
- Score与调查评价反馈


视觉类似：

完成一本研究报告。


---

# 8. 角色设计规范


## 小侦探角色


定位：

玩家化身。


要求：

- Q版
- 亲和
- 好奇
- 表情丰富


至少包含：

- idle
- thinking
- discovery
- happy
- failed


---

## 猫咪助手


定位：

游戏引导角色。


特点：

- 可爱
- 简单
- 具有陪伴感


至少包含：

- idle
- hint
- encourage
- confused


---

# 9. 生物元素规范


## 细胞设计


要求：

- 卡通化
- 彩色
- 易识别
- 不产生恐怖感


区分方式：

- 颜色
- 形状
- 装饰


禁止：

- 真实癌症图片
- 血腥元素


---

## 基因元素


包括：

- DNA
- 基因卡片
- 表达状态
- 扫描效果


风格：

科学 + 可爱。


---

# 10. 禁止风格


CancerTrace 禁止以下视觉方向。


## 科技风

禁止：

- Cyberpunk
- Futuristic HUD
- AI控制中心
- 黑蓝大屏
- 复杂数据终端


原因：

CancerTrace 是探索型生物侦探游戏。


---

## 医疗软件风

禁止：

- 医院后台界面
- 医疗管理系统
- 冰冷专业软件界面


原因：

目标用户是探索者，而不是医生。


---

## 过度真实医学风

禁止：

- 恐怖癌细胞图片
- 真实病理切片作为主要视觉
- 血腥元素


---

dark AI interface

futuristic HUD

realistic horror medical image

# 13. 美术一致性原则


所有新资源必须满足：


1. 与参考图片风格一致

2. 保持统一色彩体系

3. 保持手绘质感

4. 保持轻松探索氛围

5. 避免单独出现科技感元素


如果某素材无法融入整体视觉体系，应重新设计。
