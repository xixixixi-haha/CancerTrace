# Unity 开发文档

本目录保存客户端设计依据与开发前期规划。游戏规则以 `Game_Design_Document_v1.0.md` 为最高优先级来源；其他文档如与其冲突，应先记录差异并回到 GDD 评审，不得自行覆盖规则。

- `Game_Design_Document_v1.0.md`：v1.0 游戏设计与规则基线。
- `Systems/`：核心循环及各游戏系统的规则规格与待细化项。
- `UI_Asset_Checklist.md`：美术素材清单。
- `Scene_Plan.md`：场景职责规划。
- `Script_Architecture.md`：脚本分层与数据流原则。
- `Unity_Development_Guide.md`：Unity 开发、资源命名与协作规范。
- `Art_Style_Guide.md`：美术风格、色彩与视觉一致性规范。
- `References/`：界面与美术参考图片。
