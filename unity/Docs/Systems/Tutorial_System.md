# Tutorial 教学流程

状态：v1.0规则已同步（实现细节待补充）  
规则来源：`../Game_Design_Document_v1.0.md` 第 18 节

## 教学流程

1. 第一次启动游戏。
2. 角色介绍。
3. 进入Tutorial Case。
4. 病例档案介绍。
5. 学习免费线索。
6. 学习Gene Scan。
7. 学习Cancer Galaxy。
8. 学习AI Assistant。
9. 提交诊断。
10. 展示结果。
11. 进入正式Shift。

## 已确认规则

- 第一次进入游戏时不直接进入正式Shift。
- Tutorial不消耗RP。
- Tutorial不计入正式Shift。
- Tutorial不影响正式统计。
